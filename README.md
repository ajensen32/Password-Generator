<h1>Password Generator</h1>

<h2>Project Description</h2>
<p>This Password Generator is a simple web application that allows users to generate secure passwords based on specified criteria. The application is built using HTML, CSS, and JavaScript, and provides an easy-to-use interface for creating passwords with various options.</p>

<h2>What It Does</h2>
<ul>
    <li>Specify the length of the password (between 8 and 30 characters).</li>
    <li>Include uppercase letters.</li>
    <li>Include lowercase letters.</li>
    <li>Include numbers.</li>
    <li>Include symbols.</li>
</ul>
<p>Users can generate a password by selecting their desired options and clicking the "Generate Password" button. The generated password will be displayed in the input field, and users can copy it to their clipboard by clicking the "Copy" button.</p>

<h2>How It Works</h2>
<ol>
    <li>Open the <code>index.html</code> file in your preferred web browser.</li>
    <li>Use the form controls to specify the password length and the types of characters to include.</li>
    <li>Click the "Generate Password" button to create a password based on the selected criteria.</li>
    <li>The generated password will be displayed in the input field.</li>
    <li>Click the "Copy" button to copy the generated password to your clipboard.</li>
</ol>

<h2>Files in the Project</h2>
<ul>
    <li><code>index.html</code>: The main HTML file that contains the structure of the web application.</li>
    <li><code>index.js</code>: The JavaScript file that contains the logic for generating passwords.</li>
    <li><code>style.css</code>: The CSS file that contains the styles for the web application.</li>
</ul>

<h2>How to Run the Project</h2>
<ol>
    <li>Clone the repository from GitHub:
        <pre><code>git clone https://github.com/ajensen32/Password-Generator.git</code></pre>
    </li>
    <li>Open the <code>index.html</code> file in your web browser to start using the Password Generator.</li>
</ol>

<p>Enjoy generating secure passwords with ease!</p>
